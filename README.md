# Ambulance Management System

## About the Project
A C++ application that demonstrates basic ambulance record management and the organization of ambulance requests.

## Features
- Maintain ambulance records
- Display available ambulance information
- Register emergency requests
- Organize requests, if implemented
- Manage ambulance assignments, if implemented

## Technologies Used
- C++
- Data Structures

## Concepts Used
Queues, structures or classes, functions, and conditional statements, depending on implementation.

## How to Run
Compile the C++ source file and run the program.

## Learning Objective
To understand how programming can organize ambulance-related information and requests.
